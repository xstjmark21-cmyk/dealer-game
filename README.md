# 我是庄家

一个无需安装依赖的联网股票博弈游戏原型：公开订单簿、价格时间优先撮合、撤单、10 个机器人、实时盘口、逐笔成交和成交驱动 K 线均已可运行。

## 启动

```bash
cd "/Users/mac/Documents/ChatGPT/我是庄家"
python3 server.py
```

在同一台电脑打开 `http://127.0.0.1:8088`。同一局域网的其他设备可使用运行服务器这台 Mac 的局域网 IP 加 `:8088` 进入同一张订单簿。
